# Prompts para generar imágenes e iconos de PatitasFind

> Estilo unificado: ilustraciones 3D/cartoon con colores planos, bordes redondeados, líneas gruesas color café oscuro (#3B2F2F), paleta cálida. Fondo transparente o crema muy claro (#FFF8F0). Caras amigables, expresiones felices. Sin texto.

## Paleta de colores
- Teal/verde azulado: `#4ECDC4`
- Naranja coral: `#FF8C69`
- Lila: `#C4B5FD`
- Rosa: `#F49AC1`
- Amarillo vainilla: `#F6C344`
- Café oscuro (líneas): `#3B2F2F`
- Crema (fondos): `#FFF8F0`

## Notas para la generación

- Para imágenes con fondo transparente, pedir explícitamente **"transparent background"** o **"fondo transparente"**.
- Para iconos, preferir **SVG** escalable además de PNG.
- Mantener siempre la paleta: teal `#4ECDC4`, naranja `#FF8C69`, lila `#C4B5FD`, rosa `#F49AC1`, amarillo `#F6C344`, café `#3B2F2F`, crema `#FFF8F0`.
- Evitar texto en las ilustraciones; el texto irá en HTML/CSS.
- Para imágenes de perros específicos, usar razas variadas (beagle, labrador, golden, chihuahua, pastor alemán, etc.) pero siempre con estilo amigable y consistente.
